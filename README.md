# خطيب - تعلّم الإنجليزية عن طريق المنافسات

تطبيق ويب تقدمي (PWA) يشتغل على أندرويد وآيفون وتابلت وكمبيوتر.

## الرفع على GitHub Pages
1. أنشئ مستودع جديد على GitHub وارفع كل محتويات هذا المجلد (بما فيها .github).
2. Settings ← Pages ← Source: GitHub Actions.
3. أي push على فرع main ينشر نسخة جديدة تلقائيًا، والرابط يظهر في تبويب Actions.

## التثبيت على الجهاز
- أندرويد (Chrome): قائمة ⋮ ← تثبيت التطبيق.
- آيفون (Safari): مشاركة ← إضافة إلى الشاشة الرئيسية.

## إشعار التحديث
كل push يغيّر رقم نسخة الـ Service Worker، فيظهر للمستخدم شريط «فيه تحديث جديد» عند فتح التطبيق (يفحص كل 30 دقيقة وعند الرجوع للتطبيق).
ملاحظة: الإشعار وهو مقفول يحتاج خادم Push (خطوة لاحقة مع الباك إند).

## قيد حالي
الحسابات والبيانات محفوظة على الجهاز نفسه (localStorage). تبويب التحدي الأونلاين يعمل فقط داخل claude.ai. الحسابات الحقيقية والمنشورات والمراسلات ولوحة التحكم تحتاج باك إند.

## تفعيل الحسابات الحقيقية (Supabase)
1. أنشئ مشروع على supabase.com.
2. SQL Editor ← الصق محتوى `supabase/schema.sql` ← Run.
3. Authentication ← Providers ← Email: **أوقف Confirm email** (الدخول بيوزر وباسورد، واليوزر بيتحول داخليًا لإيميل وهمي).
4. Project Settings ← API: انسخ Project URL وanon key إلى `config.js`، وغيّر `domain` لدومين تملكه.
5. ارفع التحديث على GitHub. لو `config.js` فاضي التطبيق يشتغل بحسابات محلية للتجربة.
6. الباسوردات تتخزن مشفّرة (hash) عند Supabase. نسيان الباسورد يحتاج إعادة تعيين من الإدارة (مرحلة لوحة التحكم).
